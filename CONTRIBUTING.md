# Contributing

This project is a **Work in Progress**. Prefer a small, reproducible change that can be verified in the game over a broad conversion batch.

## Before starting

Read [STATUS](docs/STATUS.md), choose an existing issue, and state the component and resolution you intend to test. Keep unrelated rendering, font, texture, and video changes separate whenever possible.

## Evidence to include

- Game executable hash, widescreen-fix version, and enabled components.
- Reproduction steps and expected versus observed behavior.
- Test results at 1080p and 1440p, or a clear explanation of what remains untested.
- Rollback results and relevant before/after evidence.

Do not upload game archives, executables, proprietary tools, saves, or personal paths. CI checks source syntax only; local asset tests and in-game validation must be reported separately.

Write documentation, issue titles, and pull requests in English. Do not mark a feature complete based solely on generated file counts or successful repacking.
